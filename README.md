# From Scores to Behavior: A Diagnostic Evaluation Pipeline for Trustworthiness Benchmarks

This repository provides additional material for our iAIMS 2026 paper.
We provide the raw datasets, prompt templates for our manipulators, intermediary model outputs, evaluation results, and experiment results.

## Repository Structure

```
├── manipulator_templates/  # Jinja2-templates for our manipulators
├── data/                   # The datasets, intermediary results, and evaluation results for our experiments
│   ├── benchmarks/         # The datasets for our experiments
│   ├── eval_results/       # The evaluation results and intermediary results for our experiments
│   ├── task_results/       # The manipulated tasks + model responses
├── README.md               # This file
```
